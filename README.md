# 图像创作工作台

一句主题，出一整套图：方案、画风、版式、配图、成图，全都替你想好。

![界面预览](docs/preview.webp)

这是给 **DSH（DeepSeek Harness）** 用的图像创作插件。写一句「雨天街拍姿势指南，复古手绘，做 6 张」，它会先拆成封面、步骤、对比、总结，再逐张出图。

## 自动保存生成图片

打开顶部 **设置**，点击 **生成图片保存目录 → 选择文件夹…**，在目录选择器中选定目标文件夹，再点击 **保存设置**。本机 DSH 优先使用系统文件夹选择窗口；远程或浏览模式可在页面内逐级浏览并新建文件夹。以后单张和批量出图成功后，PNG / GIF 原图都会保存到这个目录，文件名包含时间和随机标识，批量任务还带图片序号。结果页会显示保存路径。

点击 **关闭自动保存** 后保存设置即可关闭自动保存。目录是运行 DSH 的电脑上的目录；如果 DSH 在服务器运行，图片会保存到服务器。自动保存的是生图接口返回的原图（GIF 不会转换成 PNG），插件里的「下载 PNG」和整套导出仍用于下载适配画幅和本地文字排版后的图片。

如果目录失效、权限不足或磁盘空间不够，生成结果仍会显示，页面会提示先下载图片并检查保存目录。

## 能做什么

- **一句话出方案**：自动拆页，每页配好画风、配色、版式和参考姿势，不满意点开素材画廊换掉
- **整套视觉统一**：角色、服装、画风、配色和一张参考图贯穿全篇，不用每页重新描述
- **素材随手换**：内置 368 组画风、36 组配色、170 种版式，点缩略图就能替换
- **平台尺寸**：小红书、抖音、公众号、B 站、Instagram、YouTube、方图、竖版
- **不丢进度**：切面板、刷新、关窗口都能接着来；成图生成中切走也不会中断
- **认得住主体**：上传的人物、宠物、商品或场景会作为主体依据，关键特征尽量保住；选了服装或姿势素材时只替换对应部分，不替换主体
- **点开看大图**：成图点一下全屏查看，可放大到 400%，方便看细节；Esc 或点背景退出，一键复制到剪贴板

## 安装

对 DeepSeek 说这一句就行：

> 帮我安装插件：https://github.com/yang0/dsh-handraw-style

它会把插件装好并提醒你启用。启用后左栏点 **AI 写真工作台** 就能用。

想自己点也行：DSH 左栏 **插件** → **添加插件** → **安装第三方插件**，粘上面的仓库地址；或者命令行 `dsh plugin --profile web add "github:yang0/dsh-handraw-style"`。

## 开始出图

生图需要一个兼容 GPT Image 的接口（OpenAI 官方或任意中转站）。打开 **接口设置**，填 Base URL 和 API Key，默认模型 `gpt-image-2`。

点 **生成方案** 会用 DSH 当前的默认模型做规划，不需要另外配文本模型。确认方案后，单页生成或批量生成，最后 **导出整套 ZIP**。批量生成使用最多 **4 路并发**，不会逐张排队；一页失败不会阻塞其他页，已完成的结果会逐页保存。

### 生成原生 GIF 动画

使用 [chatgpt2api-dsh](https://github.com/yang0/chatgpt2api-dsh) 号池新版 GIF 接口时，在 **整套 → 输出格式** 中选择 **动画 GIF**，设置帧数（2–16）与每帧时长（20–2000 毫秒，10 毫秒递增）；在接口设置选择 `gpt-image-2.6`、`gpt-image-2.6-flare` 或 `gpt-image-2.6-sunburst`。GIF 参数通过 `/v1/images/generations` 的 `output_format` / `frame_count` / `frame_duration_ms` 传递。

GIF 只走文生图：画风等素材会通过文字描述影响生成，但上传照片和整套参考图暂不支持。生成后在工作台播放动画，可下载原生 GIF；整套 ZIP 中也会保留 GIF 动画，不会经过 PNG 画布静态化。如果号池未实际返回 GIF，则会报错而不会假装转换成功。是否可用取决于号池账号的上游能力；更新号池插件后需要重启对应后端进程。

## 素材说明

画风、配色、版式是内置的，装完就能用。姿势、服装、人像图库是可选素材包（约 1.1 GB），没有它也能规划、出图和上传自己的参考图。
